# Arus — personal finance demo

Arus is a responsive, local-first personal finance web app. It pairs a public landing page with a working dashboard for recording income and expenses and setting monthly budgets. The visual direction is inspired by [Outcrowd's personal finance landing page](https://dribbble.com/shots/26496450-Promo-Landing-Page-for-a-Personal-Finance-Platform); the product, copy, layout, and assets are original.

This portfolio project uses example data. Changes are stored only in this browser on this device. There is no account, cloud sync, bank connection, or payment flow. Clearing browser site data removes saved records.
